# PPL - "Principles of Programming Languages"

Principles of Programming Languages (PPL) explores foundational and advanced concepts in programming languages through coursework and hands-on projects. This repository includes projects implemented in JavaScript, TypeScript, and Scheme, covering the following topics:

- **Functional Programming:** Learn and apply key concepts such as higher-order functions, immutability, and recursion.
- **Syntax and Semantics:** Analyze and define the formal structure and meaning of programming constructs.
- **Type Checking:** Explore static and dynamic type systems, type inference, and their applications in programming.
- **Continuation-Passing Style (CPS):** Understand and implement CPS transformations to manage control flow explicitly.
- **Logic Programming:** Dive into declarative programming paradigms, with practical examples in Scheme.

## Repository Highlights

- **Detailed Implementations:** Projects for each topic with comprehensive code examples.
- **Unit Tests:** Thorough tests to validate concepts and ensure correctness.
- **Documentation:** Explanations and comments within the code for better understanding.

## Prerequisites

- Basic understanding of programming concepts.
- Familiarity with JavaScript or any similar language is helpful.
- Scheme-specific projects may require knowledge of functional programming paradigms.

## How to Use This Repository

1. Clone the repository: `git clone https://github.com/username/PPL-Principles-of-Programming-Languages.git`
2. Navigate to the topic of interest: `cd PPL-Principles-of-Programming-Languages/<topic>`
3. Follow the README in each subdirectory for instructions on running and testing the projects.

## Tools and Dependencies

- JavaScript/Node.js for JavaScript and TypeScript projects.
- Racket or another Scheme interpreter for Scheme projects.
